# 微信高仿 App 使用手册

本手册面向 Android App 版本（Capacitor 打包），介绍如何自定义你自己的「微信」：修改头像、昵称、个人资料，编辑好友，发布朋友圈，以及导入真实聊天记录。

> 这是一个用于截图、演示、素材制作的高仿界面工具，所有数据都存在本机，不联网、不产生真实聊天。

## 一、两种模式

App 有两种工作状态：

- **预览模式（默认）**：和真微信一样正常浏览，点击、滑动都是浏览行为。
- **编辑模式**：点击界面上的任意元素会弹出对应的编辑面板，用来改头像、文字、朋友圈等内容。

所有修改都是**改完即存**，自动写入本机存储，不需要手动点保存。

---

## 二、进入和退出编辑模式

App 模式下，编辑入口默认是**隐藏**的，避免误触。开启步骤：

1. 打开底部的 **「我」** 页面。
2. 在「我」页面上 **长按屏幕**（按住约 0.3 秒），底部设置区会多出几个开发入口。
3. 点击其中的 **「编辑模式」**，即进入编辑状态。

进入编辑模式后：

- 屏幕顶部出现一条**绿色提示条**，点它即可随时**退出编辑模式**，回到正常预览。
- 需要改哪里，就点哪里。被点中的元素会弹出一个**底部编辑面板**（抽屉），在里面改内容。
- 面板里改完直接关掉即可，内容已自动保存。

> 长按只是把开发入口显示出来，离开「我」页面后入口会重新隐藏；真正进/出编辑模式分别是点「编辑模式」和点顶部绿条。

## 三、编辑我的资料

进入编辑模式后，打开 **「我」** 页面，**点击顶部的头像/昵称区域**（或进入「个人信息」页点击任意处），底部弹出「我的资料」编辑面板。

可编辑的字段：

| 字段 | 说明 |
| --- | --- |
| 头像 | 点击选择本机图片，自动存入 App |
| 昵称 | 必填 |
| 微信号 | 必填 |
| 个性签名 | 一行个人签名 |
| 性别 | 男 / 女 |
| 地区 | 例如「广东 深圳」 |
| 朋友圈背景图 | 你朋友圈顶部的大图 |
| 朋友圈可见范围 | 全部 / 最近三天 / 半年等 |
| 拍一拍文本 | 别人拍你时显示的后缀 |
| 微信豆个数 | 显示用的数字 |

**换头像**：在面板里点头像那一项 → 从本机相册/文件里选一张图片 → 自动完成，返回即可看到新头像。

**改昵称**：在「昵称」输入框直接改字，改完关闭面板生效。

## 四、编辑好友资料

有两个入口，都要先进编辑模式：

- **通讯录**：进入通讯录，点击某个好友那一条。
- **好友详情页**：进入某个好友的资料页，点击页面任意处。

弹出的「好友资料」面板比「我的资料」多了这些字段：

- **备注**：你给对方起的备注名（显示优先于昵称）。
- **星标好友**：是否标星置顶。
- **电话**：可以加多条号码。
- **标签**：给好友打标签，可增删多个。
- **描述**：补充说明。
- **朋友权限**：聊天+朋友圈 / 仅聊天 / 不让他看我 / 我不看他。
- **朋友圈缩略图**：好友资料页上展示的朋友圈小图，最多 5 张，支持拖拽排序。
- 以及头像、昵称、微信号、签名、性别、地区、朋友圈背景等（同「我的资料」）。

**提示**：图片类字段（头像、背景、缩略图）都是点一下从本机选图，多图可以拖动调整顺序、点删除去掉。

## 五、新建一个好友

1. 进入编辑模式。
2. 打开 **通讯录** 页面，点击联系人**列表的空白容器区域**，弹出「新建好友」面板。
3. 填写资料（**头像、昵称、微信号为必填**），其余字段同好友资料。
4. 点面板底部的 **「创建」**，新好友会追加到通讯录。

## 六、编辑朋友圈

朋友圈入口：底部 **「发现」** → **「朋友圈」**。

进入编辑模式后可以做这些操作：

- **新增一条朋友圈**：点朋友圈列表（会出现「新增朋友圈」的操作），生成一条以当前用户、当前时间为默认的空动态，再点进去改内容。
- **删除**：点中某条动态上的删除操作，确认后移除。
- **调整顺序**：直接拖拽动态卡片重新排序。
- **改正文**：点动态的文字区域，用富文本编辑（支持 emoji）。
- **配图 / 视频**：一条动态的内容是三选一——纯文字、文字+图片（1 张或多张，多张自动排成九宫格）、或视频（封面图+播放按钮）。
- **点赞**：预览模式下点动态可切换「我」的点赞；编辑模式下可增删点赞用户。
- **评论**：新增评论会生成一条占位评论，进编辑模式改文字或删除；评论支持「回复某人」。
- **换朋友圈封面**：在朋友圈顶部点「换封面」，进入编辑选背景图（这张图实际存在资料的「朋友圈背景图」字段上）。

每条朋友圈包含：发布者、发布时间（界面显示为「几分钟前」这种相对时间）、内容（文字/图片/视频）、点赞列表、评论列表。

## 七、导入真实聊天记录

你可以把微信导出的聊天记录（文字 + 图片）导入进来，自动生成对应的聊天气泡。

### 1. 准备导出文件

从微信导出聊天记录后，你会得到：

- 一个 **`聊天记录.txt`**（纯文本的对话内容）。
- 若干**图片附件**，和 txt 在同一个文件夹里。

支持两种常见导出排版，程序会自动识别：

- 每条消息三行一组（昵称、完整时间、内容）。
- 日期分隔行 `————— 2020-03-11 —————` + `昵称 时间` 同行 + 内容。

图片在文本里写作 `[图片]` 或 `[图片: 文件名(请在附件中查看)]`，程序会去同目录找对应图片文件。**表情（[表情]、[动画表情] 等）会被自动忽略，不生成消息。**

### 2. 打开导入入口

进入编辑模式的开发入口（「我」页面长按），会看到三个导入选项：

| 入口 | 适用场景 |
| --- | --- |
| **导入聊天记录（文件夹）** | 桌面浏览器推荐，直接选整个导出文件夹 |
| **导入聊天记录（选文件：txt+图片）** | **手机推荐**，一次框选 txt 和所有图片 |
| **导入聊天记录（eml 文件）** | QQ 邮箱「导出聊天记录」生成的 .eml 文件，图片已内嵌，选一个文件即可 |

> ⚠️ **手机上请优先用「选文件」或「eml」入口**。安卓手机对「选文件夹」支持不稳定，经常只能选到 txt、选不到图片，导致提示找不到附件图片。而 .eml 把正文和图片打包在一个文件里，手机导入最省事。

> 💡 **同一个人可以多次导入**。预览窗口里不勾「覆盖已有记录」时，新导入的消息会和已有记录**按时间自动合并**，完全重复的消息会被过滤，不重复的按时间顺序插入。

### 3. 核对并导入

选好文件后会弹出**预览窗口**，确认这几项：

- **顶部提示**：显示解析出多少条消息、读到多少个附件。
- **哪一方是「我」**：下拉选择哪个昵称算作「我」（气泡显示在右侧绿色）。
- **对方导入到哪个联系人**：
  - 留空 → 自动**新建**一个以对方昵称命名的联系人。
  - 选已有联系人 → 导入到这个人的对话里。
- **转账 / 红包金额**：导出文件不含金额，这里统一填一个值（如果记录里有转账或红包才会出现）。
- **是否覆盖**：勾选「覆盖该联系人已有的聊天记录」会清空原对话再导入；不勾则追加到现有记录后面。
- 下方表格可以逐条预览消息，**附件文件名标红表示没找到对应图片**（这时记得换「选文件」或「zip」入口重新选）。

确认无误后点 **「开始导入」**。完成后会提示导入了多少条消息、多少张图片，以及有几个附件没找到。

### 4. 支持的消息类型

文本、图片、语音（带时长）、转账、红包、视频、系统提示等都会转换。其中文本、图片、语音、转账能较好还原；红包/转账金额靠你在导入界面手填；无法识别的类型会降级成居中的系统提示。

## 八、常见问题

**Q：改了东西没保存？**
A：编辑模式下所有修改都是实时自动保存的，不需要手动保存。改完关掉面板即可。

**Q：找不到编辑入口？**
A：在底部「我」页面上**长按**屏幕把开发入口显示出来，再点「编辑模式」。离开「我」页面入口会重新隐藏，这是正常的防误触设计。

**Q：导入时提示「找不到附件图片」？**
A：多半是手机用「文件夹」入口没选到图片。改用 **「选文件（txt+图片）」** 入口，在文件选择器里把 txt 和所有图片一起多选；或者用 QQ 邮箱导出成 **.eml** 文件，图片已内嵌，用 eml 入口导入最省事。

**Q：导入后聊天记录左右反了？**
A：在导入预览里重新选「哪一方是我」。

**Q：数据会上传吗？**
A：不会。所有资料、聊天记录、图片都只存在你本机的 App 存储里。

**Q：想重新开始/清空数据？**
A：可以新建一个资料档（profile）从头配置，不同档的数据互相隔离。
